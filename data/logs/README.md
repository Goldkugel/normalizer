# data/logs

Log files written by the [`logger`](https://github.com/Goldkugel/logger) package while `Normalizer` runs (by default `output.log`, see the `logger` section of [`config/config.yaml`](../../config/config.yaml)).

The logger appends to its file but does not create this folder, so it is kept in the repository. The log files themselves are ignored by git (`*.log` in [`.gitignore`](../../.gitignore)).
