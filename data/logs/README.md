# data/logs

Default folder for the log files written by the [`logger`](https://github.com/Goldkugel/logger) package while `Normalizer` runs (`output.log`, see the `logger` section of [`config/config.yaml`](../../config/config.yaml)).

The logger creates the folder if it is missing; it is kept in the repository so the log location is visible. The log files themselves are ignored by git (`*.log` in [`.gitignore`](../../.gitignore)).
